Reusable agent skills for building on Sui. Install them into Claude Code, Cursor, Codex, and 40+ other AI coding agents through the `skills` CLI.

Browse available skills:

```sh
npx skills add mystenlabs/skills --list
```

Install all skills:

```sh
npx skills add mystenlabs/skills --all
```

Install a specific skill:

```sh
npx skills add mystenlabs/skills --skill move
```
